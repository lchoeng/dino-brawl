# Dino Brawl

A 2D Street Fighter–style game starring **Linus** (gray dino, breathes fire) and **Wesley** (red dragon, tail spin).

Open `index.html` in a browser (or turn on GitHub Pages for this repo) to play.

## Controls
- **Phone/tablet:** on-screen buttons (turn sideways for a bigger screen)
- **Player 1:** A / D move · W jump · J punch · K slam · L special
- **Player 2:** ← / → move · ↑ jump · `,` punch · `.` slam · `/` special
- Hold the direction away from your opponent to block. Best of 3 rounds.

Sprites are cut from the original character video at full resolution (`L.webp`, `W.webp`).
